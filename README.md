# Sunny Sharma - Developer Portfolio

Personal portfolio highlighting Sunny Sharma's MERN and React Native development work, including the DriveOnyx vehicle-rental platform, selected projects, experience, education, and technical skills.

## Run locally

```bash
npm install
npm run dev
```

## Build and lint

```bash
npm run build
npm run lint
```

## Portfolio content

- Update profile details, projects, experience, and skills in `src/lib/data.js`.
- The downloadable resume is served from `public/Sunny_Sharma_Resume.pdf`.
- Project artwork is stored in `src/lib/img/`.
- Search metadata and crawler-readable page content are in `index.html`.
- Crawler directives and the sitemap are in `public/robots.txt` and `public/sitemap.xml`.
